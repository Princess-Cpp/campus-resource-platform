# M2 实现与验收记录

基线：模块设计与集成总约定 v0.2，Git 168380b；本轮用户确认范围为 M2 业务，不包含正式登录和完整主数据管理。需求 M2-01.1–01.5、M2-02.1–02.3。尚未人工验收、组内评审或发布。

方案：M2 独立保存申请、冻结审批人/政策、审批轨迹、幂等命令和资源操作。业务与审计/通知事件同事务写入。以版本和行锁串行化同一申请的动作；不跨 HTTP 持有业务事务。最终审批通过现有 M1 HTTP operations/receipt 接口执行，回执确认前保留同步中。超时按原 operationId 查询/重试，持久化重试次数与下次时间，重启补扫；超过自动重试上限需人工重试同一操作。只释放本申请的 M2 来源。

数据：新增版本化 SQL 迁移，不改既有 M1 schema；测试使用独立 MySQL 库。开发身份/空间适配器提供明确申请权限、院系/场地范围、容量和联系方式引用，不将座位数当容量。正式 D-01/D-02 未交付。资源 HTTP 请求字段与当前 M1 一致，不修改 M1 业务实现；本轮接口和新 schema 仍须组内评审。

暂按需求提案实现两级、4 小时、提前 14 天、24 小时审批期限（不晚于开始），配置与流程在提交时冻结；不代表 DEC 已确认。统计使用完整授权 SQL 集合，批准/驳回决定为通过率分母，撤销后的历史批准仍计入已作出的批准决定。

验收计划：后端真实 MySQL + HTTP 覆盖创建/幂等、权限/数据范围、自审批/跳级、版本竞争、冲突、释放来源、到期和响应丢失后的重启恢复；关键权限或回执规则故意破坏后确认测试失败再恢复。前端仅构建检查，UI 和点击操作由用户人工验收，不编写或运行前端自动化测试。

本轮实现与验证结果见下节；前端人工验收仍待完成。外部通知投递、正式身份/主数据、M3 维修影响接入、审批人重派和完整资源对账继续跟踪，不声明完成。

## 运行与人工验收

预览使用独立数据库 campus_m2_preview，后端 127.0.0.1:8081，Vite 127.0.0.1:5175；不会复用此前 M1 验证库。正式重启时，先创建独立 MySQL 空库（schema 由迁移入口执行），配置 MYSQL_DSN（包含 parseTime=true）和至少 32 字节 M1_CODE_SECRET，然后执行 `scripts/dev-m2.sh`。另开终端执行：

```sh
cd frontend
npm ci
VITE_BACKEND_URL=http://127.0.0.1:8081 npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

M2_ENABLED 默认关闭，避免改变已有 M1 启动配置；dev-m2.sh 显式打开。M2_RESOURCE_URL 与 LISTEN_ADDR 必须对应，M2_SERVICE_TOKEN 由环境传入（脚本仅默认公开开发 fixture 标识）。新迁移沿用已有迁移锁和校验表，并按文件名顺序执行；001 文件内容未改动。

侧栏左下角切换开发身份：student-demo 提交和查询本人申请；department-demo 处理 CS 院系第一步；venue-demo 处理 A楼最终批准/开始后紧急终止；operator-demo 查看 A楼聚合统计。用真实表单提交未来整点申请，再依次切换两名审批人，最后回申请人查看/撤销。最终批准与撤销后等待约 2 秒或刷新详情，确认状态由“确认中”收敛。统计对学生拒绝访问属于预期行为。

可修改 dev-fixture.json 的 m2Policy 后重启服务调整未来申请的政策，旧申请保留快照。当前 M1 可用性查询有 4 小时限制，M2 开发配置 maxHours 仅支持 1–4；更长时段需共同扩展资源查询契约。没有可用座位的教室目前不会出现在结果中；不能据此宣称覆盖无座位教室的完整场地模型。

## 剩余工作与评审边界

- D-01/D-02 正式 SQL 身份、登录、主数据和参数管理不在本轮范围；开发 fixture 不等同正式交付。公开 M2 API 初稿在 contracts/m2.openapi.json，需组内评审。
- 通过现有 M1 v1 availability / operations / operations/{id} HTTP 接口，按当前字段解码回执并检查 operationId/sourceModule/sourceBusinessId/sourceVersion。没有直接读写 M1 业务表；测试中读库仅作为验收断言。现有资源契约仍需 M1/M2 共同评审，不虚构批准记录。
- 通知当前为 M2 业务 outbox，尚未接入 M3 的站内/外部实际投递；审批事件为 M2 本地业务审计，不代表 D-03 公共审计查询已交付。共享任务库未交付，当前以 M2 资源操作记录进行业务恢复，不新建通用调度服务。
- 自动重试最多 8 次，之后标为待处理；手动重试沿用同一操作。若资源给出永久版本冲突，需共同诊断来源，不自动清空或覆盖来源。
