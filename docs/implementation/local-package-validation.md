## 制品和隔离方式

先以当前前端执行 `npm run build`。将 backend 源码复制到 `.git/release-check/2026-10-23/source/`，只在副本内用新 frontend/dist 替换 cmd/server/webdist，执行：

```bash
go build -mod=readonly -trimpath -buildvcs=false -o ../campus-server ./cmd/server
```

制品包含实际前端，不是仅使用旧 embed 内容编译。未运行 `npm install`、`go mod tidy` 或更改锁文件。该制品为本机 macOS/arm64 开发候选，正式 Linux 镜像/生产构建和签名仍未验证。

临时进程只监听随机 loopback 端口，M1/M2/M3 同时启用。M2/M3 资源URL都指向此进程；数据库在本机独立测试MySQL，使用新建、专用于本次验证的空库，不连接日常演示库。账号和服务配置依旧是显式开发模式，不冒充生产公共层。SMTP未配置，没有发送真实物业或公网邮件。

数据库创建只是隔离测试环境的置备；业务表全部由已有版本化迁移创建，没有手工修改业务schema或工单/预约数据。使用公开注册HTTP接口新增虚构学生。两次启动后临时进程均已退出；测试库与备份保留在私有环境供追溯，未删改演示数据。
