## 使用方式

- 原任务书是课程要求来源，M2/M3/D 文档是基于该来源细化的项目提案，不能将建议参数冒充课程原文。
- 用户补充的 SQL、review 与技术选择另行记录；不修改原 PDF 以混入这些补充。
- M1 组阅读附件 1 的全部要求；现有概要不替代原文，也不代表已经完成实现与验证。
- 改动需求时检查来源和验收映射，并保留未完成项；原任务书若更新，应保存新版本及来源说明，不覆盖后假装原文件从未变更。
